# CURIO — котики и компания

Учебный сайт керамической мастерской по актуальным [макетам Figma](https://www.figma.com/design/zHfnsTafFG3pUndLGqzVU2/?node-id=127-1601). Опубликован на [GitHub Pages](https://pinkx1.github.io/cda-handmade-preview/).

15 фигурок в трёх категориях: котики, жабки и Смешарики. На компьютере — свободная композиция каталога; на телефоне — три горизонтальные ленты. У каждого товара открывается окно с фотографией, ценой, размером и весом. Корзина сохраняет выбранные фигурки и количество в localStorage.

Это учебный проект: реальные заказы не принимаются. Кнопки «Написать мне» и «Заказать по фото» никуда не ведут. Оформление и пункт СДЭК — демонстрационные: доставка 650 ₽ взята из макета, запросы к СДЭК и платёжным сервисам не выполняются. Имя, телефон и почта никуда не отправляются и не сохраняются; при закрытии формы поля очищаются. Изображения иллюстративные.

Статический HTML, CSS и JavaScript без сборки и внешних зависимостей. Изображения, SVG и шрифты хранятся локально. GitHub Pages публикует корень ветки `main`.

Запуск из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`.

Проверки:

```sh
node --check script.js
node tests/cart.cjs
```

В браузере проверены ширины 1440, 390 и 320 px: окна товаров, добавление, изменение и удаление товаров, сохранение после перезагрузки, пустая корзина, демонстрационная доставка и оформление. Диалоги поддерживают Escape и изоляцию фокуса; анимация учитывает reduced motion.

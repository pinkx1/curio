# CURIO — котики и компания

Учебный сайт керамической мастерской по актуальным [макетам Figma](https://www.figma.com/design/zHfnsTafFG3pUndLGqzVU2/?node-id=127-1601). Опубликован на [GitHub Pages](https://pinkx1.github.io/curio/).

15 фигурок в трёх категориях: котики, жабки и Смешарики. На компьютере — свободная композиция каталога; на телефоне — три зацикленные горизонтальные ленты. Карточка выравнивается по центру, а с обеих сторон видны края соседних карточек, в том числе у первого и последнего товара. Ленты поддерживают свайп и клавиши ←/→; на узких экранах карточки уменьшаются, сохраняя подсказку о прокрутке. У каждого товара открывается окно с фотографией, ценой, размером и весом. Корзина сохраняет выбранные фигурки и количество в localStorage.

Это учебный проект: реальные заказы не принимаются. Кнопки «Написать мне» и «Заказать по фото» никуда не ведут. Оформление и пункт СДЭК — демонстрационные: доставка 650 ₽ взята из макета, запросы к СДЭК и платёжным сервисам не выполняются. Имя, телефон и почта никуда не отправляются и не сохраняются; при закрытии формы поля очищаются. Изображения иллюстративные.

Статический HTML, CSS и JavaScript без сборки и внешних зависимостей. Изображения, SVG и шрифты хранятся локально. GitHub Pages публикует корень ветки `main`.

Запуск из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`.

Проверки:

```sh
node --check script.js
node tests/cart.cjs
```

Браузерная проверка мобильного каталога (нужны Playwright и Google Chrome, сервер должен быть запущен):

```sh
node tests/catalog.cjs
```

Для опубликованного сайта передайте `CURIO_URL=https://pinkx1.github.io/curio/`.

В браузере проверены ширины 1440, 768, 390 и 320 px: окна товаров, добавление, изменение и удаление товаров, сохранение после перезагрузки, пустая корзина, демонстрационная доставка и оформление. Диалоги поддерживают Escape и изоляцию фокуса; анимация учитывает reduced motion.
